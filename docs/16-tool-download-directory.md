## Tools that are not universally available from an official public download page

- Odin: Samsung service utility; use authorized sources and Samsung service guidance.
- SP Flash Tool: MediaTek service utility; use only trusted, model-compatible packages and authorized instructions.
- Research Download / Upgrade Download: Unisoc service utilities; source and authorization depend on OEM.
- QFIL / QPST: Qualcomm service ecosystem; programmer files and EDL access are device-specific.
- Xiaomi Mi Flash: verify the current supported procedure with Xiaomi's official support/service channel; do not rely on random mirrors.

Do not treat search-engine ads, Telegram links, file-sharing mirrors or “cracked” installers as trusted sources.

## Installation checklist

1. Download only from the publisher or an authorized service provider.
2. Check the publisher and digital signature where available.
3. Scan the installer with Windows Security.
4. Read the supported OS and device list.
5. Install only the driver required for the target model.
6. Record tool version and source in the repair worksheet.
7. Never install unknown USB drivers or loaders just to make a device appear.

**Phone-only note:** You can read and bookmark this directory from Android. Installing Windows utilities and drivers requires a Windows computer.
